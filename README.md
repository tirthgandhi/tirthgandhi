## About me

I'm **Tirth Gandhi**, a developer who enjoys turning real-world problems into useful web applications and clear data experiences. My work spans full-stack development, responsive UI design, data preprocessing, visualization, and applied machine learning.

- 🔭 Currently building a **Campus Bus Pass Management System** with role-based workflows and secure transport records
- 🌱 Growing my skills in **React, TypeScript, backend architecture, and applied machine learning**
- 🤝 Open to collaborating on impactful web, data, and open-source projects
- 💡 I value clean interfaces, maintainable code, and technology that solves a genuine problem
