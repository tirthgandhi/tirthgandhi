## About me

I'm **Tirth Gandhi**, a developer working across **full-stack web development and data analysis**. I build practical applications and work with data from cleaning and preprocessing through exploration, visualization, and predictive modeling.

- **Data cleaning & preprocessing** — handling missing values, removing duplicates, and preparing datasets for analysis.
- **Exploratory data analysis** — investigating customer behavior, sales trends, and patterns in real-world datasets.
- **Data visualization** — presenting findings through clear charts and visual comparisons that make results easier to understand.
- **Applied machine learning** — exploring feature engineering and predictive workflows through projects such as employee attrition prediction.
- **Full-stack development** — connecting responsive interfaces, backend services, and databases to solve everyday problems.

Currently building the **Campus Bus Pass Management System** and developing my skills in React, TypeScript, backend architecture, and data analysis. Open to collaborating on web applications and data projects.
